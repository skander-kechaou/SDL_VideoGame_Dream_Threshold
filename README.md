# Dream Threshold 🎮

**Dream Threshold** is a 2D adventure game built in **C** using the **SDL** library suite. Developed on a **Ubuntu virtual machine** using a simple text editor, this project blends code and art, featuring original hand-designed characters, environments, and animations.

## 🌟 Game Overview

You play as a dream-traveling character (animated cutout of team member **Yasmine Bahri**) navigating a surreal world. The game features:

- 🧍 **Free Movement**: Explore the game world with fluid character control.
- ❓ **Quests & Enigmas**: Solve interactive riddles and questions to progress.
- 👾 **Enemy Avoidance**: Dodge enemies strategically to survive.
- 🗺️ **Minimap System**: See your position and navigation path in real time.
- 🎨 **Original Art**: All visuals (backgrounds, characters) were custom-made using **Photoshop** and **Illustrator**.

- **C Language**

- **Adobe Photoshop** & **Adobe Illustrator** (for art assets)

## 🚀 How to Build & Run

### 1. Install Dependencies (Ubuntu/Debian)

```bash
sudo apt-get update
sudo apt-get install build-essential libsdl1.2-dev libsdl-image1.2-dev libsdl-mixer1.2-dev libsdl-ttf2.0-dev
```

### 2. Build the Game
```bash
make
```

### 3. Run the Game
```bash
./game
```
